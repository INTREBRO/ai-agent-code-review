# Evaluation data attribution

This project references, but does not bundle full repositories from, two public benchmark datasets:

- CloudAEye/c_cpp_benchmark, pinned revision `60733901a3deef2c7128b883cde420fea86d2186`, MIT license: https://github.com/CloudAEye/c_cpp_benchmark/blob/60733901a3deef2c7128b883cde420fea86d2186/LICENSE
- alibaba/aacr-bench, pinned revision `68a569759289a83654a59d06db2a72910edf0a4a`, Apache License 2.0: https://github.com/alibaba/aacr-bench/blob/68a569759289a83654a59d06db2a72910edf0a4a/LICENSE

The manifest includes short issue descriptions, source PR links, pinned commit IDs, and human-review discussion links. Code fetched during evaluation remains in a local cache and is not committed to this repository. The original projects and reviewers retain their respective attribution and licenses.
